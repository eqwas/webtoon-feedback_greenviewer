# GreenViewer — 웹툰 원고 검수·피드백 뷰어

웹툰 원고를 보고, 고칠 곳에 바로 피드백을 그리고, 표시한 부분만 모아 메일·카톡으로 보내는 Windows 프로그램입니다.

이 저장소는 **설치 파일 배포용**입니다.

## 내려받기

**[최신 버전 설치 파일 받기](https://github.com/eqwas/webtoon-feedback_greenviewer/releases/latest)** — 릴리스 페이지 아래쪽 Assets의 `GreenViewer-<버전>-setup.exe`

- Windows 10 / 11 (64비트)
- 현재 사용자 계정에 설치되며 관리자 권한은 필요 없습니다.
- Windows의 PC 보호 창이 뜨면 [추가 정보] → [실행]을 누르세요.

## 주요 기능

- 이미지·PSD·PDF·압축 파일(ZIP·CBZ·7Z·RAR·TAR)을 풀지 않고 바로 보기
- 세로 스크롤 / 한 장 / 두 장 보기, 폭맞춤·꽉차게·1:1, 여백 자르기
- 수정 전·후 원고를 나란히 놓고 함께 스크롤하며 비교
- 펜·지우개·텍스트·말풍선·이모지·올가미·캡쳐 등 피드백 도구 (원고별 자동 저장)
- 피드백 미리보기에 영역을 모아 메모를 달고 메일·카톡용으로 복사, `.gv` 파일로 저장·불러오기
- 웹소설 원작 각색용 소설 패널

자세한 사용법과 단축키는 프로그램에서 `F1`을 누르면 볼 수 있습니다.
